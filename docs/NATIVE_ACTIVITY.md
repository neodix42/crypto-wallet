# Native activity evidence

> Historical campaign scope: the encrypted-file restore and backup cases below describe the preceding API. Current native activity also covers pending phrase recording/confirmation and known-phrase import; file backup/restore operations have been removed. Previous wall-clock/native results retain their original source scope. See [PHRASE_RECOVERY.md](PHRASE_RECOVERY.md) and [FRONTEND_SIGNER_TESTS.md](FRONTEND_SIGNER_TESTS.md) for current verification.


Recorded 2026-10-23 on Linux amd64, Go 1.27.3. These are implementation and local test results, not an external security audit. All test inputs are public synthetic values.

The signer installs a native GDK event dispatcher that recognizes only key presses and mouse button presses. It inspects the event type alone, passes every event unchanged to GTK, and never reads key text, key codes, pointer coordinates or credential values for activity. Focus, redraw, timer and programmatic entry changes do not produce activity. The dispatcher mechanism is shared by GTK's X11 and Wayland backends; only X11 has been tested here.

`secureui.SetActivity` attaches a value-free callback for one active private request and limits notifications to one per second. The signer sends an `activity` frame with exact body `{}` and the active request's ID and session. It removes the callback before writing the actual response and on deferred cleanup. These notifications stay on the inherited signer/coordinator pipes; no credential input is forwarded to Electron.

`supervisor.Child.Call` consumes these notifications before the final response. It verifies the active request ID, private session, method, empty body and absence of error fields before invoking `Child.OnActivity`. It limits callbacks to one per second and rejects more than 64 frames in a one-second window. Invalid or late frames terminate the child rather than updating activity. Killing a child interrupts a pending native request. The coordinator must install `OnActivity` at initialization to update its existing user-activity timestamp; a notification does not itself unlock a session.

The coordinator installs that callback and binds queued requests, native completions, private child calls and public network contexts to their acceptance epoch. `Child.Generation` / `CallAt` prevent a delayed handler from starting a fresh native process after lock. Idle checks and lock transitions use the same mutex as activity updates; the old child is terminated before a new epoch can read its snapshot. A lock cancels existing public contexts and drops configured adapter references. Endpoint settings are applied to fresh adapters and swapped only after an epoch check, so a stale settings response cannot restore RPC credentials. Go strings still held by an in-flight request cannot be promised immediate erasure.

An initial create/unlock/restore prompt is tracked as pending while the wallet remains locked and network access stays denied. Its input refreshes the same five-minute idle timestamp; inactivity terminates its secret-bearing child. The current worker also forwards only value-free, matching-ID/session activity to Electron so its pending native request timer does not expire while the user is typing. Native requests use a six-minute outer timer, while the coordinator's five-minute real inactivity limit remains authoritative. Late, malformed, unsolicited or flooding events fail closed.

Idle signer IPC reading runs in one bounded reader goroutine. The GTK thread processes up to 64 pending native events every 20ms while idle, which allows its public clipboard ownership to serve independent desktop consumers. `Pump` uses nonblocking GTK iteration. No activity is generated by its timers or clipboard events; only the input dispatcher can notify the current private request.

Reproduce private input acceptance with `python3 scripts/native-input.py`; add `--long` for the separate five-minute wall-clock typing campaign. It uses an installed Xvfb or the existing test-only `.tools/xvfb/root/usr/bin/Xvfb`, refuses occupied displays and cleans up the process on exit. It clears inherited Wayland/runtime/session-bus settings for the isolated X11 display. Reports use separate `native-input` and `native-input-long` names; missing prerequisites are **BLOCKED**. The automation source and XTest helper are absent from production builds. The short automation suite covers 98.1% of the instrumented native package including its test-only helper. Merged production-only figures and remaining branches are recorded in `docs/COVERAGE.md` and `reports/coverage.json`. Coverage does not establish the unrun desktop/display matrix.

Run private IPC and recovery regressions with:

```sh
go test -race -cover ./internal/supervisor
go test -race -cover ./cmd/wallet-core
go test -race ./internal/signer -run 'TestWrongProfile'
```

An absence of native events must continue to expire the coordinator's session. Background polling and timers must not refresh its inactivity timestamp.
