## Current phrase recovery and desktop

The owner now requires Electron for every application window. Go generates the random BIP39 root after app-password entry, durably encrypts it, authors the recording prompt and verifies three separately entered words. Password/import/recording/receive/approval/configuration/file dialogs all use Electron. Each credential/phrase prompt has a separate origin, preload and fresh nonpersistent session; the portfolio has no prompt retrieval/reply API. Go still enforces password checks, pending-root continuity, all-profile recovery gates, immutable plan validation, signature checks and durable state. Existing encrypted vaults keep their keys and profiles. Cancellation preserves pending setup; confirmed roots have no repeat reveal/export action. The app password does not derive addresses.

This intentionally expands the trusted secret path to the coordinator/supervisor, Electron main and the dedicated prompt renderer/preload. Transient credential/phrase frames are the explicit exception to secret-free IPC; ordinary public requests/snapshots, logs, files, browser storage, clipboard, QR and network payloads remain secret-free. Compromise of trusted prompt/main code can capture secrets or spoof the display; Go generation does not eliminate this risk. The new coordinator startup protection disables and self-checks core dumps/dumpability while preserving TCP RPC. The signer remains IP-isolated. Electron inherits the launcher's zero core-size limit, but a blanket post-exec Electron non-dumpable guarantee is not established; see [ELECTRON_INTERFACE.md](ELECTRON_INTERFACE.md) and [THREAT_MODEL.md](THREAT_MODEL.md).
The final [fresh-installation drill](evidence/phrase-recovery.json) passed all six checks against three independent application copies, each with new processes, HOME/config directories and vaults. The headless real prompt-protocol test used a randomly generated phrase and restored all nine mainnet wallets at indices 0, 1 and 127: 27 exact public descriptors. Same-password and different-password restores matched, restarted locked, and unlocked identically. Only binaries/manifests were copied between installation trees; no wallet file or keyring state was reused. Public IPC, persisted files and process logs passed the tested plaintext/hex/base64 secret-canary checks. This simulates another machine on one host; separate physical-machine testing remains NOT_RUN.

The final [installed portable X11 drill](evidence/packaged-recovery.json) passed 20 checks: invalid password/phrase guidance, random phrase setup and incorrect-word denial, pending Send/Receive completion controls, cancellation, Electron reauthentication and QR continuation, generated-phrase recovery in an empty profile, independent fixture addresses, table copy/balances, Settings journal, displayed-QR decoding and Electron public-address copy, Send form, tab closing, restart/unlock, isolated testnet and additional account tabs. Logs contained neither Mesa loader errors nor ordinary IPC handler stacks. Only public/disposable fixture addresses reached read-only providers; Send testing stops at the form. Owned private Xvfb, no debug port or sandbox bypass, and memory-only synthetic phrase OCR were used. The GUI drill covers default 12 words; actual installed sending was not performed. Real hardware, full Wayland workflows and the supported installed OS matrix remain NOT_RUN.

The [current Electron interface checklist](ELECTRON_INTERFACE.md) and [phrase policy history](PHRASE_RECOVERY.md), [recovery instructions](RECOVERY.md), [desktop/signer tests](FRONTEND_SIGNER_TESTS.md), [layout](WALLET_LAYOUT.md) and [actions](WALLET_ACTIONS.md) describe behavior and limits. ## Distribution and remaining gates

`make build` creates Go components without Node/Electron or Debian packaging. `make package-go` verifies their runtime versions and archives them; these backend assets have no standalone main wallet interface. The optional complete desktop uses `make install`, providing `./wallet` plus its managed runtime without altering profiles. Neither built distribution reads `.tools`, which remains an untracked developer/test cache. VERSION or the validated WALLET_VERSION override supplies the executable, desktop, archive and workflow tag/release version. The versioned development prerelease workflow was implemented and linted; remote execution/publication remains NOT_RUN. See [BUILD.md](BUILD.md).

All nine mainnet networks and eleven assets remain supported. Earlier read-only provider checks passed 29 assertions across eight domains. Authenticated synchronized Decred mainnet access is BLOCKED until an operator configures trusted TLS dcrd; the wallet remains visible with unknown balance. Earlier container startup probes remain BLOCKED by Chromium sandbox configuration. No sandbox bypass was applied. Limited preceding X11/virtual-Wayland startup evidence is not full OS acceptance.

Resource limitations remain: bounded Decred scanning with a 10000-row internal ceiling, TON history searches of 100 transactions, 1MiB IPC frames, no general paginated desktop retrieval and a 100000-request replay cap per continuously active IPC session. Incomplete/oversized data is an error, never verified zero. A phrase cannot resolve installation journal uncertainty, whole-directory rollback, OS/display compromise or already copied secrets. Native clearing is best effort, not proof of erasure from every library/display buffer.

Production release remains incomplete: public funded testnet roundtrips and applicable third-party wallet/version interoperability; clean Ubuntu 24.04/26.04 X11/Wayland, lock/suspend/install/upgrade/recovery acceptance; complete process/crash/canary campaign; 24-hour workload; independent threat/vault/adapter/build review; licensing and publisher authentication. `make verify-release` fails until mandatory evidence passes. The current [traceability table](traceability.json) distinguishes passing local invariants from those broader NOT_RUN/BLOCKED gates. A development prerelease does not close them. No publisher authentication/update mechanism or independent audit is claimed.
