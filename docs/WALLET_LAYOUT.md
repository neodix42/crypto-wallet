# Wallet table, Settings and receive/send interactions

The current owner instruction replaces encrypted portable backups with a written recovery phrase confirmed in the native Go signer. The former encrypted-file creation, verification and restore controls are removed. After choosing the app password, a new wallet shows its phrase only in Go, asks the user to record it and confirms selected words. An empty installation offers **Restore from recovery phrase**. The phrase and any explicitly used BIP39 passphrase reproduce canonical wallets; the app password protects local encryption and does not determine addresses.

The overview uses a semantic table with Network, Assets, Native balance and Receive address columns. Click a row, or press Enter/Space on a focused row, to open that wallet's tab. The copy icon uses native verified copy without opening the row. Addresses stay single-line with a full tooltip. Each visible wallet's native balance is queried once per current descriptor/provider configuration, with one background request at a time. Refresh balances requests a new observation. Base/Horizen show ETH; HyperEVM and HyperCore retain separate HYPE observations. Exact integer-string formatting preserves precision; missing, malformed, incomplete and failed observations remain unknown or unavailable.

Wallet tabs initially show balances and network details. Send opens its otherwise hidden form. If phrase setup is incomplete, the form offers **Finish recovery phrase setup** and preparation remains gated on every profile. Completing the native setup preserves exact asset/recipient/amount/memo only for the unchanged original form and never prepares or sends automatically. Closing the form clears its local draft and rejects delayed form replies. Closing a form/tab never cancels a durable preparation, broadcasts, retries or releases a reservation. Middle-click or Delete closes wallet tabs while account tabs remain; inactive close preserves the active form and focus, and active close returns to the account table.

Receive opens the authoritative Go QR/address window once phrase setup is confirmed. Incomplete setup offers explicit native confirmation guidance first; only successful confirmation for the unchanged wallet/view/session continues to that QR. Cancellation, incomplete confirmation, navigation, tab closing and lock discard the continuation. The exact copy address comes separately from signer-owned display text. Copy address keeps the native window open; Done alone does not copy. Decred durably advances its receive descriptor before display; a committed response updates its own public row after navigation but cannot survive lock or replace another wallet's view.

The top-right Settings button contains create/restore/unlock, pending phrase setup, password change, deterministic account addition, bounded index recovery and the Local payment journal. Journal wallet/asset selectors operate independently of Send. Reconciliation preserves original operation identities; unsigned cancellation clears a visible plan only when IDs match. Context changes discard delayed results/errors. The modal traps focus, makes the background inert and dismisses by Escape, Close or backdrop. Credential actions close Settings before Go opens. Named/rotated account association uses its own public-address field in network details.
